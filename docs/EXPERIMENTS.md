# 实验与复盘记录

> 只记录能帮助未来重新理解、复现、排错的内容。没有值得记录的新发现，可以不写。
> 写完后先尝试闭卷复述一次；没想起来的地方再查这里。

## 简短模板（复制后填写）

### YYYY-MM-DD · [实验/问题标题]
- **预测：** 我以为会发生什么？
- **观察：** 实际发生了什么？测试条件是什么？
- **解释：** 哪个证据支持/推翻原先判断？
- **入口：** 场景 / 脚本 / Godot 版本 / Git commit（确有其值再填）。
- **下次回忆：** 一个不看笔记就应该回答的问题。
