# liumasimulator — 当前计划（Godot）

**状态：** 起步 / PC 原型。此文件是当前唯一的阶段目标来源；有实测结果后随时修改。

## 本机实测状态（2026-11-12）

- Godot **4.7.2**，渲染后端目前是 **mobile**，Windows 下走 D3D12。
- `application/run/main_scene` 为空，还没有主场景；`scenes/`、`scripts/` 是空目录。
- MCP 插件 `godot_mcp_toolkit` v1.1.2 在跑，编辑器侧检查可用（`scene.get_tree` 现在返回 `NO_SCENE`，符合"没有打开场景"）。
- Git 仓库 `git@github.com:rhx2001/LiuMaSimulator.git`，分支 `main`。

### 渲染后端：定在 mobile

PC 只是**功能验证环境**，最终目标是移动端，所以从一开始就用 mobile 跑，避免"PC 上好好的、一上手机全变样"。这条已经定了，不再为了 PC 画质切 Forward+。

代价是接受一组能力边界（Godot 4.x 官方文档）：

- **能用**：RenderingDevice、CompositorEffect 自定义后处理、compute shader（有性能警告）、2D HDR 视口、MSAA 2D、粒子拖尾 / SDF 碰撞、粒子尾迹。
- **用不了**：SDFGI、VoxelGI、SSAO、SSR、体积雾、TAA、FSR2、次表面散射、contact shadows。

这些缺失**几乎都是 3D 特性**；本项目是 2D/2.5D，真正会撞上的只有以后可能做的"玻璃折射 / 环境光遮蔽"。

后期确实需要扩能力时的顺序：先用 `CompositorEffect` + RenderingDevice 在项目层解决 → 再不行用 GDExtension 写 C++（不改引擎） → 最后才是 fork 引擎改 mobile 后端。fork 之后要自建导出模板，并且每次升级 Godot 都得 rebase。

## 一句话目标

用 Godot 做一个**填满窗口的透明流麻容器**：亮粉和亮片可随重力方向移动；用等效阻尼参数表达不同流麻油；在后续阶段实现明显的闪烁与反光。

## 当前取舍

- **引擎：** Godot 4.7.2（本机实测）；渲染器 mobile。
- **平台：** 先在 PC 上验证（PC 只作验证环境），最终目标是移动端；因此渲染后端固定为 mobile，不为了 PC 上的画质切 Forward+。

**维度：倾向 3D + 正交相机**（观感接近 2.5D，但每颗粒子有真实朝向和深度）。2D 方案保留作为对照。等读完教程、并确认「要不要真实粒间堆积」之后定稿。
- **控制：** PC 键盘/鼠标修改重力和实验参数，优先使用 GDScript。
- **模拟：** 2D 用 GPUParticles2D、3D 用 GPUParticles3D 先验证运动；如遇无法表达的约束（尤其粒间堆积），再评估 RigidBody3D / MultiMesh / 自定义模拟。
- **流麻油：** 初期是等效阻尼、重力比例与外观材质，不宣称真实流体动力学。
- **边界与堆积：** 第一个里程碑只要求稳定可见的运动；边界约束独立验证；不默认内置粒子系统支持粒间真实碰撞与堆积。
- **光照：** 先做简单的亮片高光可视化；前摄估计、AR 和系统动态壁纸推迟到 PC 核心效果完成后。

## 分阶段任务与验收

### M0：空项目可检查
- 确认 `project.godot`、Godot 版本、渲染器和场景入口。
- 利用已连接 MCP 只读检查场景树并报告真实状态。
- 可以启动场景并查看错误输出。**不要求已有任何粒子效果。**

### M1：第一批小圆点（当前优先）
- 在二维容器区域内看到可重复生成的约 20～100 个点状颗粒。
- 清楚区分场景节点、粒子生成参数、粒子更新与绘制方式。
- 可以重置或重新运行实验；能描述粒子生命周期。

### M2：受控运动和等效油
- PC 端改变重力方向；粒子运动跟随变化（先确认具体 Godot API/Shader 写法）。
- 至少两档阻尼参数产生稳定、可对照的区别。
- 判断表现对帧率和初始参数是否敏感；保证实验可重复。

### M3：颗粒差异与光学外观
- 区分小闪粉和较大亮片的尺寸、旋转或运动参数。
- 用最小材质实验观察光照/高光；避免初期堆叠昂贵的透明层。
- 验证关闭视觉油层后，粒子轨迹不应变化。

### 后续候选（不是当前任务）
- 矩形边界与粒子堆积近似、粒间碰撞研究、2D 流场、Compute Shader。
- 可切换真实摄像头光照/手动灯光、移动端设备传感器。
- 进一步了解 Godot 渲染管线、RenderingDevice、GDExtension。

## 关键工程规则

- 一个实验只改变一个主要因素，保留可复现参数；效果不符合预期先做最小测试。
- 不为了“架构优雅”提前设计通用粒子框架；只有出现真实复用需求时才抽象。
- 每次结束先汇报可观察结果，再讨论下一步。
- 新概念先尝试自己解释，再让 Agent 补充遗漏，尽量避免只是复制粘贴。
