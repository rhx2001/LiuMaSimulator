## 目标

做一个能看、能玩的「流麻」模拟器：麻将牌外壳里悬浮着上千片闪粉，随倾斜缓慢流动，翻面时闪一下。

## 当前阶段

**M0 · 可行性验证**（进行中）

先不碰玻璃、折射、3D。用 2D 粒子验证两件事：

1. 这个观感能不能用 GPU 粒子做出来
2. 5000 片在 mobile 渲染后端上跑不跑得动

## 技术选择

| 项 | 选择 | 原因 |
|---|---|---|
| 引擎 | Godot 4.7.2 | 轻量、开源、GDScript 迭代快，适合边学边做 |
| 渲染后端 | mobile | 目标平台是手机；桌面调试也先用它，早暴露性能问题 |
| 起步维度 | 2D | 先验证观感和吞吐，3D 玻璃后面再加 |
| 粒子 | `GPUParticles2D` + 自定义 `shader_type particles` | CPU 粒子撑不住上万片 |
| 推进方式 | 一次一个可验证的小实验 | 学习与开发同等重要 |

## 实验 1（待你确认）

**问题**：`GPUParticles2D` 能不能做出「悬浮闪粉」的观感，并在一台普通机器上跑满 5000 片 60 FPS？

**做法**

- 一个竖屏场景（1080×1920），深色背景
- `GPUParticles2D` 发射 5000 片；`shader_type particles` 里写流场：低频噪声 + 缓慢涡旋 + 阻尼
- 粒子贴图用白色小方块，渲染时随机旋转、加色混合
- 左上角 Label 实时显示 FPS 和粒子数（方便截图验收）

**验收**

- 视觉上像「悬在液体里的粉」，不是「喷泉」
- 稳定 60 FPS，以截图里的 FPS 数字为准
- 粒子不会穿出边界

**风险**：mobile 后端对 particles shader 的支持、加色混合的亮度溢出。
